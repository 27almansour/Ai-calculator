# 🤖 آلة حاسبة ذكية بالذكاء الاصطناعي

مشروع متطور يتضمن نسختين من الآلات الحاسبة الذكية مع واجهات مستخدم جميلة وميزات متقدمة!

---

## 📱 النسخ المتوفرة

### 1️⃣ **الحاسبة الذكية الأساسية** (index.html)
آلة حاسبة ذكية مع مساعد ذكي متطور

#### ✨ الميزات:
- 🧮 العمليات الحسابية الأساسية (الجمع، الطرح، الضرب، القسمة)
- 🔢 العمليات المتقدمة:
  - الجذر التربيعي (√)
  - الأس (x²)
  - الدوال المثلثية: sin, cos, tan
  - الدوال اللوغاريتمية: log
  - الثوابت الرياضية: π (باي)، e (عدد أويلر)

- 🧠 **المساعد الذكي**:
  - يجيب على الأسئلة الرياضية
  - يشرح الدوال والعمليات
  - يقدم نصائح مفيدة

- 📋 **السجل والذاكرة**:
  - حفظ آخر 20 عملية
  - إمكانية النقر على أي عملية سابقة
  - حفظ تلقائي باستخدام localStorage

- 🎨 **تصميم جميل**:
  - واجهة مستخدم حديثة وجذابة
  - تصميم متجاوب (Responsive)
  - رسوم متحركة سلسة
  - ألوان زاهية وتدرجات لطيفة

### 2️⃣ **الحاسبة العملاقة** (Supercomputer)
حاسبة علمية متطورة جداً مع محول وحدات شامل

#### 🧪 الميزات العلمية:
- ⚙️ **حاسبة علمية متقدمة**:
  - دعم الدوال المثلثية (sin, cos, tan)
  - الدوال اللوغاريتمية (log, ln)
  - الجذر التربيعي والأس
  - المضروب (factorial)
  - النسبة المئوية
  - الثوابت الرياضية (π, e)

- 🔄 **اختيار بين أنماط الحسابات**:
  - DEG (الدرجات) - الوضع الافتراضي
  - RAD (الراديان)

- 💾 **ذاكرة الحاسبة**:
  - M+ (إضافة للذاكرة)
  - M- (طرح من الذاكرة)
  - MR (استرجاع من الذاكرة)
  - MC (مسح الذاكرة)

- 📊 **محول وحدات شامل** (10 فئات):
  1. **الطول**: متر، كيلومتر، سنتيمتر، مليمتر، ميل، ياردة، قدم، إنش
  2. **الوزن/الكتلة**: كيلوغرام، غرام، طن، رطل، أونصة
  3. **درجة الحرارة**: مئوية، فهرنهايت، كلفن
  4. **الحجم**: لتر، مليلتر، متر مكعب، جالون، كوب
  5. **السرعة**: م/ث، كم/س، ميل/س، عقدة
  6. **الزمن**: ثانية، دقيقة، ساعة، يوم
  7. **المساحة**: متر مربع، كيلومتر مربع، هكتار، فدان
  8. **البيانات**: بايت، كيلوبايت، ميجابايت، جيجابايت، تيرابايت
  9. **الطاقة**: جول، كيلوجول، سعرة حرارية، كيلوواط ساعة
  10. **الضغط**: باسكال، بار، ضغط جوي، رطل/إنش²

- 📈 **سجل العمليات**:
  - حفظ آخر 12 عملية
  - عرض النتيجة بوضوح
  - إمكانية مسح السجل بنقرة واحدة

## 🚀 كيفية الاستخدام

### الحاسبة الذكية الأساسية:
```
1. أدخل التعبير الرياضي
2. انقر على "=" أو اضغط Enter
3. ستظهر النتيجة والسجل
4. استخدم المساعد الذكي لطرح أسئلة
```

### أمثلة:
- `15 + 25` = 40
- `√16` = 4
- `sin(90)` = 1
- `π × 2` = 6.2832

### الحاسبة العملاقة:
```
1. اختر بين الحاسبة العلمية أو محول الوحدات
2. للحاسبة: أدخل العملية وانقر "="
3. للمحول: اختر الفئة والوحدة والقيمة
4. ستظهر النتيجة على الفور
```
